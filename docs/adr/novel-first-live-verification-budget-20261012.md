## 决定

仅对 PR #68 从合并基线到候选头的这批小说验证变更申请文件数预算例外；不调整全局门禁，不豁免测试、真实数据库隔离要求或用户确认门禁。记录实际文件数和净新增行数，由 CI 对本次累计差异逐项核对。

## 范围与理由

本包处理小说方向到试写的模型输出校验、隔离 MySQL 回读、试写章节正式化、长等待和结果入口交互，并对单章正文的真实模型质量作隔离 canary 验证及窄范围请求修正；同时将用户确认的章节字数容差统一为上下各 15%；包含对应单测、DOM 测试、烟测脚本和验收记录。临时数据库脚本保留本地测试库约束和 mock provider；正文 canary 单次调用且不写库。正常正文 Prisma 写链、全书审稿/完本、真实模型长篇质量均未借此放行。

超限主要来自跨前后端的同一用户流程和相应证据文件。若后续继续扩展正文写链、任务平台或更多页面，不得继续堆到这份 ADR；应另拆可独立验收的变更。
