# 小说章节字数现行规则

2026-10-12 用户确认：章节正文实际字符数允许相对该章目标值上下各偏差 15%。此规则替代 `RP-04B-L1` 历史冻结契约中的 90%-115% 区间；历史验收证据不回写。

设当前权威章节目标为正整数 `T`，正文实际字符数为 `A`：

- 下限 `L = ceil(T * 85 / 100)`，上限 `U = floor(T * 115 / 100)`。
- `L <= A <= U` 合格，边界包含在内；`A < L` 为偏少，`A > U` 为偏多。
- 例：目标 2,300 字，1,955-2,645 字合格；1,954 和 2,646 字不合格。此前实际 2,880 字的样本仍不合格。

字数沿用 `unicode_code_point_non_whitespace_nfc_v1`：先 NFC 归一化，去除 Unicode 空白，再按非空白 code point 计数，标点计入。前端仅展示预估区间；服务端以当前权威章节目标重新计算生成结果和采用资格，不信任旧候选保存的门禁或前端数值。

第 1 章候选、第 2-3 章试写、批量正文、单章生成和重写均适用。模型提示中的允许区间与服务端门禁保持一致，但建议输出仍尽量接近目标字数。

2026-10-13 增补的限次修订**仅供显式隔离试验，正式 DeepSeek provider 默认关闭**：批量正文和单章正文首次返回合法结构但 `content` 偏多时，试验模式在同一生成任务内追加最多一次完整 AI 修订调用；合格、偏少或首轮结构错误均不触发。修订请求携带完整原稿、权威目标和既有剧情约束，要求同步更新摘要、特性卡、审稿和记忆。每章最多两次付费调用、无传输或 JSON 自动重试；批次中多章分别计数，等待和费用可能明显增加。修订提示词超过 40,000 字符时跳过第二次调用，由原有字数门禁拒绝原稿。修订后仍越界就按原门禁失败，不继续调用；任何越界正文都不能写成正式版本。任务失败后的再次生成仍由用户显式触发。

试验模式下，现有批量正文在最终校验通过后仍会直接写正式版本，超长原稿只在任务执行期间供修订使用，**尚未作为可查看的非正式候选持久化，也没有双版本人工采用界面**。真实试验已出现大幅缩短和事实变更，故试验模式不得在正式服务开启。长度合格也不代表情节连贯，现有固定词锚点和模型自评分无法替代内容复核。在候选持久化、采用门禁、内容质量复核和 Prisma 正文写链完成前，不得宣称该部分已验收。
