# 小说章节字数现行规则

2026-10-12 用户确认：章节正文实际字符数允许相对该章目标值上下各偏差 15%。此规则替代 `RP-04B-L1` 历史冻结契约中的 90%-115% 区间；历史验收证据不回写。

设当前权威章节目标为正整数 `T`，正文实际字符数为 `A`：

- 下限 `L = ceil(T * 85 / 100)`，上限 `U = floor(T * 115 / 100)`。
- `L <= A <= U` 合格，边界包含在内；`A < L` 为偏少，`A > U` 为偏多。
- 例：目标 2,300 字，1,955-2,645 字合格；1,954 和 2,646 字不合格。此前实际 2,880 字的样本仍不合格。

字数沿用 `unicode_code_point_non_whitespace_nfc_v1`：先 NFC 归一化，去除 Unicode 空白，再按非空白 code point 计数，标点计入。前端仅展示预估区间；服务端以当前权威章节目标重新计算生成结果和采用资格，不信任旧候选保存的门禁或前端数值。

第 1 章候选、第 2-3 章试写、批量正文、单章生成和重写均适用。模型提示中的允许区间与服务端门禁保持一致，但建议输出仍尽量接近目标字数。

2026-10-13 增补的限次修订**仅供显式隔离试验，正式 DeepSeek provider 默认关闭**：批量正文和单章正文首次返回合法结构但 `content` 偏多时，试验模式在同一生成任务内追加最多一次 AI 删句调用；合格、偏少或首轮结构错误均不触发。服务端枚举可删除的完整句子，模型只选最多 12 个句子编号，服务端从中取删减量合规且句数最少的组合，精确删除和重新计数；模型不能改写整章或添加新事实。需删除超过原稿 12%、提示词超过 40,000 字符时跳过第二次调用。每章最多两次付费调用、无传输或 JSON 自动重试；批次中多章分别计数，等待和费用可能明显增加。没有合规组合、调用失败或结果仍越界时退回并保存原稿候选，不继续调用；任何越界正文都不能写成正式版本。任务失败后的再次生成仍由用户显式触发。

超长原稿现已保存为可回读的非正式候选，批次停在该章，后续章节不生成；实验删句模式若明确打开且得到合格结果，原稿和修订稿会分别保存为候选，即使修订稿字数合格也不能自动成为正式正文。用户点击发起的精简、手工编辑、逐版本内容复核和采用流程仍未开放，因此实验修订不是可交付的完整恢复操作。全文重写的真实试验出现过大幅缩短和事实变更；局部删句的真实回放也尚未获得可接受的内容质量结论，正式服务不得开启实验模式。长度合格不代表情节连贯，固定词锚点和模型自评分不能替代内容复核。隔离 MySQL mock smoke 已覆盖原稿候选回读和正式资产防误写；真实模型质量与完整采用闭环仍待验证。
