# 小说章节字数现行规则

2026-10-12 用户确认：章节正文实际字符数允许相对该章目标值上下各偏差 15%。此规则替代 `RP-04B-L1` 历史冻结契约中的 90%-115% 区间；历史验收证据不回写。

设当前权威章节目标为正整数 `T`，正文实际字符数为 `A`：

- 下限 `L = ceil(T * 85 / 100)`，上限 `U = floor(T * 115 / 100)`。
- `L <= A <= U` 合格，边界包含在内；`A < L` 为偏少，`A > U` 为偏多。
- 例：目标 2,300 字，1,955-2,645 字合格；1,954 和 2,646 字不合格。此前实际 2,880 字的样本仍不合格。

字数沿用 `unicode_code_point_non_whitespace_nfc_v1`：先 NFC 归一化，去除 Unicode 空白，再按非空白 code point 计数，标点计入。前端仅展示预估区间；服务端以当前权威章节目标重新计算生成结果和采用资格，不信任旧候选保存的门禁或前端数值。

第 1 章候选、第 2-3 章试写、批量正文、单章生成和重写均适用。模型提示中的允许区间与服务端门禁保持一致，但建议输出仍尽量接近目标字数。
